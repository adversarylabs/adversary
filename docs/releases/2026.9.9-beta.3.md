# 2026.9.9-beta.3

Fixes source-verification failures caused by invalid model citations or source-read requests during composed review.

- Supply exact citation IDs and inclusive absolute line ranges to the verifier.
- Explain structural validation errors and allow at most two corrections per evidence stage, without rerunning completed specialist reviews or changing valid decisions.
- Keep the existing single evidence-fetch pass, strict citation/path validation, cancellation, and unresolved-result failure behavior. Invalid requests are never executed; exhausted corrections do not become successful reviews.
- Preserve each correction's output, error, input digest, usage, evidence round, and attempt number in an explicitly requested private verification report. Offline replay follows the same inputs.

No configuration migration or deprecation. Correction calls can add latency only on malformed decisions. Missing evidence and provider failures can still leave a review incomplete. Roll back by selecting beta.2; published tags are immutable.

Validation: verifier regression tests cover oversized reads, out-of-range/invented citations, traversal rejection, bounded correction, independent peers, no quality rerolls, and offline replay. `govulncheck v1.6.0` reported no reachable vulnerabilities (one advisory only in required modules outside imported packages).
